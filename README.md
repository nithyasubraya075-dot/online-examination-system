# Online Examination System

## Project Description
The Online Examination System is a web-based application that allows students to attend examinations online. It helps teachers manage exams, questions, and student results.

## Features
- Student registration and login
- Admin and teacher management
- Online examinations
- Question management
- Automatic result generation
- Student dashboard

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven
